# ts-packages

Shared building blocks for Opulon websites, published as `@opulonjs/*` packages: `core`, `ui`, `admin`, `users`, `emails`, `media` and `cms`. See [GLOSSARY.md](GLOSSARY.md) for the terms and [docs/adr](docs/adr) for the decisions.

ESM only, Node 24, Effect 4. Development setup: [CONTRIBUTING.md](CONTRIBUTING.md). Security: [SECURITY.md](SECURITY.md). Licence: [MIT](LICENSE).
