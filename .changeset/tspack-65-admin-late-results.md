An unmounted admin no longer changes the page around it. A language save that fails after the admin unmounted shows no error toast in the admin mounted after it, and a sign-in or any other router navigation that resolves after the unmount leaves the browser URL where the host moved it. Language saves from one admin now run one at a time, each after the previous one answered, so the language picked last in that admin is the one the server keeps. A second pick waits for the first save's answer before it is sent. A pick still waiting when the admin unmounts, or when the shell already shows another user or a new sign-in, is not sent, and it no longer holds back the language of that new sign-in. While a pick waits, the shell keeps the language it shows and still applies everything else the server answers, such as a sign-out or a new deploy. Admins on one page never wait for each other's saves, and when two of them save a language, the save that reaches the server last wins, as before.
